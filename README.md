# HexTactics Server Build

Publieke bronrepository voor de originele HexTactics FiveM-resources, database-installatie en het installatie-recept.

## Inhoud

- `resources/[HexTactics]/hextactics_core`
- `resources/[HexTactics]/ht_vehiclekeys`
- `resources/[HexTactics]/ht_chopshop`
- `resources/[HexTactics]/ht_rdw`
- `resources/[HexTactics]/ht_customdealer`
- `installer/` met SQL, configuratie, commando's, beveiligingsnotities en testverslagen

## Belangrijk

Third-party scripts, MLO's, voertuigen, kleding en andere assets worden alleen opgenomen wanneer hun licentie openbare herdistributie toestaat. Onduidelijk gelicentieerde of escrow-bestanden staan niet in deze publieke repository.

De serverresources gebruiken ESX Legacy, oxmysql, ox_lib, ox_inventory en ox_target volgens de installatiehandleiding.
