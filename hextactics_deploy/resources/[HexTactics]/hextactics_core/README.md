# HexTactics Core v2.0

Centrale bron voor kenteken-normalisatie en ESX-voertuigeigendom.

Belangrijkste commands:
- `/htvehiclefix` migreert legacy `license:` eigendom naar de actieve ESX-character identifier.
- `/htvehicledebug KENTEKEN` toont de exacte database-eigenaar en huidige speleridentifier.

De vergelijking is karakterbewust: `char1:` en `char2:` zijn nooit dezelfde eigenaar.
